CONTROLE DE APOSTAS — VERSÃO 20

ESCUDOS OFICIAIS AUTOMÁTICOS
- Ao selecionar um time, o aplicativo consulta a imagem principal do artigo do clube na Wikipédia.
- O escudo é exibido no cabeçalho, dashboard e tela de aparência.
- O aplicativo tenta baixar e salvar uma cópia local do escudo.
- Depois de salvo, o escudo pode continuar aparecendo sem internet.
- Caso o download local não seja possível, a URL segura da imagem é salva.
- Caso a imagem não carregue, aparece automaticamente o emblema estilizado anterior.
- É possível enviar uma imagem própria para substituir o escudo automático.
- O botão “Usar escudo oficial automático” restaura e baixa novamente o escudo.

NOME DO APLICATIVO
- O nome permanece sempre Controle de Apostas.
- O time selecionado altera somente cores, escudo e identificação discreta do tema.

FONTE DAS IMAGENS
- Imagem principal do artigo de cada clube na Wikipédia em português.
- O carregamento usa a API pública MediaWiki com suporte a CORS.

ATUALIZAÇÃO
1. Extraia o ZIP.
2. Substitua todos os arquivos no GitHub.
3. Faça Commit changes.
4. Abra com ?v=20.
5. Na primeira seleção de cada time, mantenha a internet ativa para baixar o escudo.
