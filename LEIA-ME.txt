ARQUIVOS NECESSÁRIOS
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

ENVIE TODOS PARA A RAIZ DO REPOSITÓRIO NO GITHUB.

COMO INSTALAR NO ANDROID
1. Abra o endereço do aplicativo no Google Chrome.
2. Toque no botão "Instalar app", caso apareça.
3. Se não aparecer, toque nos três pontos do Chrome.
4. Escolha "Adicionar à tela inicial" ou "Instalar aplicativo".
5. Confirme.

Depois disso:
- O aplicativo aparecerá junto com os outros apps.
- Abrirá em tela cheia, sem a barra do Google.
- Poderá funcionar mesmo sem internet após a primeira abertura.
- Os dados continuarão salvos no próprio celular.

IMPORTANTE
Não abra o arquivo index.html diretamente pelo gerenciador de arquivos.
Ele precisa estar publicado no GitHub Pages para a instalação funcionar.
