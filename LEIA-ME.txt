CONTROLE DE APOSTAS — VERSÃO 29

CORREÇÃO DA PERSISTÊNCIA
- Os dados agora usam uma chave permanente: controleApostasData.
- Novas versões não criarão mais uma chave diferente para cada atualização.
- A versão 29 procura automaticamente os dados das versões anteriores.
- Ao encontrar dados antigos, migra para a chave permanente.
- Imagens grandes de escudos não são mais salvas junto com os dados financeiros.
- O escudo oficial é armazenado como URL leve.
- Se o armazenamento estiver cheio, o aplicativo reduz históricos auxiliares e tenta novamente.
- Uma cópia de recuperação é criada após importações.
- O aplicativo tenta salvar também quando a página é fechada ou colocada em segundo plano.
- A área “Mais” mostra o horário do último salvamento.
